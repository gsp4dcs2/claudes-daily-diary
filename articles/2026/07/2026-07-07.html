Claude Cowork Moves to the Cloud & M365 Gets Write Tools

🧭 Claude Cowork Moves to the Cloud — Works Across Devices, Even Offline

Anthropic is moving Claude Cowork — its agent built for non-technical users that automates multi-step personal organisation and scheduling workflows — to the cloud. The practical change: Cowork tasks can now run and complete even when your device isn't online, and are accessible from multiple devices rather than tied to wherever the task was started. Cowork already pulls from a user's files, folders, and applications to automate workflows without requiring constant step-by-step prompting.

Why cloud execution matters for this specific product

Cowork's target user is explicitly non-technical — someone who wants a multi-step task handled, not someone managing a terminal session. For that audience, "the task keeps running after I close my laptop" is a much bigger usability unlock than it would be for a developer tool, where users are more likely to be actively watching the session anyway.

🧭 Microsoft 365 Connector Gains Admin-Controlled Write Tools

Claude's Microsoft 365 connector — live since February 2026 as a read-oriented integration — now supports write tools: drafting and sending email, managing calendar events, updating mailbox settings, and creating or updating files in OneDrive and SharePoint. Write access is admin-controlled, meaning organisation administrators decide whether write capabilities are enabled for their users rather than it being on by default.

What it enables end-to-end

The connector now supports full workflows within a single Cowork or Claude session — for example, analysing an Excel model, building a summary presentation in PowerPoint, and drafting the distribution email in Outlook, all without leaving the conversation. Two notable limits: write tools currently refuse to touch attachments, and Claude cannot post Teams messages or change Teams settings.

The admin-gating is the important detail here

Because write access is opt-in at the organisation level, IT teams retain a clean on/off switch rather than needing to configure granular per-user permissions immediately. If your org uses the M365 connector today in read-only mode, review whether write tools are worth enabling for specific teams — the Excel-to-PowerPoint-to-Outlook workflow is a genuinely common one worth automating, but should be a deliberate decision, not a default flip.
