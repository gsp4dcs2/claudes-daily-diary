Auto Mode Reaches Bedrock, Vertex AI & Foundry

🧭 Claude Code Auto Mode Now Works on Bedrock, Vertex AI, and Foundry

Auto mode — Claude Code's unattended execution mode — is now available when running through AWS Bedrock, Google Vertex AI, and Microsoft Foundry, not just Anthropic's direct API. Cloud-platform deployments now default to Claude Opus 4.8 for auto mode specifically, a deliberate choice given auto mode's unattended nature tends to favour the more capable tier for teams running it through enterprise cloud infrastructure.

Why this matters for enterprise teams specifically

Teams that adopted Claude Code through a cloud platform for procurement or compliance reasons (rather than the direct API) previously had a narrower feature set — this release closes that gap for auto mode specifically. If your organisation runs Claude Code via Bedrock, Vertex, or Foundry and has been waiting on auto mode parity with the direct API, it's now available.

🧭 Agent View, Remote Control, and Background Sessions All Get More Reliable

The same release improves agent view, Remote Control, and background sessions, and fixes a cluster of stability issues: freezes, crashes, credential handling problems, and a security consent bug. None of these are individually headline features, but together they represent the kind of reliability polish that matters most for teams already running Claude Code at scale, where an occasional freeze or credential glitch compounds across many concurrent sessions.
