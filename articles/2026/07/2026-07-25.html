Claude Code Adopts Opus 5 as Default & Expands Nested Subagents

🧭 Claude Code Makes Opus 5 the Default, Expands Dynamic Workflows and Nested Subagents

A day after launch, Claude Code adopted Claude Opus 5 as its default Opus-tier model, and expanded both dynamic workflows and nested subagent capabilities — the multi-agent-spawning-agents pattern that shipped in June, now handling more complex orchestration scenarios. The same release improves behaviour across MCP, sandbox, the model picker, and Remote Control.

Worth re-testing nested subagent workflows after this update

If you built nested subagent orchestration when the feature first shipped and hit limitations around complex scenarios, this expansion is worth a fresh look — the June release covered the basic capability, but "expanded" releases like this one are typically where the rough edges from initial launches get addressed.
