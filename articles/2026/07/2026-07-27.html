✅ Shared Claude Conversations Turned Up in Google Search — Check Your Own Share Links

A number of Claude conversations that users had made public via the "share" feature were found indexed in Google search results, with some reportedly containing sensitive information including cryptocurrency wallet keys and personal details like names and addresses. The affected content came specifically from chats users had actively chosen to share — the issue is that shared links, once public, are crawlable by search engines the same as any other public web page, which isn't always the mental model users have when they hit "share."

What to actually check right now
  • Review any Claude conversation you've previously shared publicly — if it contains anything sensitive (credentials, personal data, private business information), revoke or delete the share link.
  • Treat "share" as equivalent to "publish publicly on the web," not as a private link to send to one person — that's the safer mental model regardless of how the feature is actually designed.
  • Never paste secrets — API keys, wallet keys, passwords — into a conversation you might later share, even if you don't plan to share it at the time.
